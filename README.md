# DefiTie

Empowers decentralized, cross-platform trading with real-time processing and auto-scaling system engine capabilities.

With DefiTie, you get a lightweight tool that stays out of your way.

**What you get**

- Empowers decentralized, cross-platform trading with

- engine capabilities

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DefiTie.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DefiTie is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
